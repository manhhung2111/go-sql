# internal/wiring

## Purpose

Google Wire dependency injection: builds the gRPC `Server` and its dependencies, and returns a cleanup function that closes the catalog.

## Depends on / Must not import

Imports `internal/config`, `internal/engine`, `internal/grpcserver`, `internal/parser` and `github.com/google/wire`.

## Files

| File | Responsibility |
| --- | --- |
| `wire.go` | Build-tagged `wireinject` source: `WireSet` and the `InitializeServer(cfg)` injector declaration |
| `wire_gen.go` | Generated by Wire; do not edit by hand; regenerate with `make generate` |
| `providers.go` | `ProvideDataDir(cfg)` and `ProvideCatalog(dataDir)` |

## Key types and entry points

- `InitializeServer(cfg *config.Config) (*grpcserver.Server, func(), error)`.
- `WireSet` combines `parser.WireSet` (`NewLexer`, `NewParser`), `grpcserver.WireSet` (`NewServer`), `engine.WireSet` (`NewEngine`), `ProvideDataDir` and `ProvideCatalog`.
- `ProvideCatalog` opens the catalog with `engine.NewCatalog` and returns a closure that calls `catalog.Close()` and logs a failure.

## Called by / calls

Called by `cmd/server`'s `main`. Calls `engine.NewCatalog`.

## Gotchas

- After changing `wire.go`, regenerate with `PATH="$(go env GOPATH)/bin:$PATH" make generate`; `wire` is not on `PATH` in a fresh shell.
- The cleanup function must run on every exit path after `InitializeServer` succeeds; `main` calls it after `GracefulStop` and before `log.Fatalf` on listen or serve errors.
