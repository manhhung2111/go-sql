# Heap `File.Get(RowID)` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `Get(id RowID) ([]byte, error)` to the heap `File` so a caller can read one row by address without scanning, with a sentinel `ErrRowNotFound` that separates a stale address from a damaged file.

**Architecture:** One new method on `sqlFile` that reads the page through the page file (like `Scan`), validates the slotted layout, looks up the slot and returns a copy of the row. No on-disk format change, no change to `Insert`, `Delete` or `Scan`.

**Tech Stack:** Go 1.26.4, `bytes`, `errors`, testify (`assert`/`require`).

**Spec:** `docs/specs/2026-10-12-heap-get-design.md`

## Global Constraints

- Go 1.26.4; `internal/storage` never imports `internal/parser` or `internal/engine`; only `internal/storage/file.go` and `file_test.go` change.
- `ErrRowNotFound` ("row not found") wraps, via `%w`, every address with no live row: page outside `[0, NumPages)`, slot outside `[0, SlotCount)`, or a deleted slot. Every other failure (I/O, bad checksum, wrong page number, inconsistent layout) is a different error.
- The returned bytes are a copy owned by the caller; a live zero-length row returns a non-nil empty slice.
- `Get` reads through the page file, never the cached tail page, and touches no mutable state, so it may run concurrently with other `Get`s and with `Scan`s.
- Error messages: lowercase, no trailing punctuation, "out of range [lo, hi)" phrasing. `Delete`'s existing messages do not change.
- Run `gofmt -w internal/storage/` after each edit.

## Review Focus

- A corrupt page must not look like a stale address: the corruption test asserts `NotErrorIs(ErrRowNotFound)`. Pinned in Task 1.
- A negative page or slot is "not found", never a panic. Pinned in Task 1.
- Modifying a returned slice must not change later reads, including over a cached page file, where a view would corrupt the shared buffer. Pinned in Task 1.
- A live empty row is not a tombstone. Pinned in Task 1.
- The slot-range check is observable only through its error message, so the table asserts the message. Pinned in Task 1.

func TestSqlFile_Get(t *testing.T) {
	t.Run("returns each row by the id Insert gave, before and after a reopen", func(t *testing.T) {
		f, path := newTestFile(t)
		const n = 3000 // about 13 bytes a row with its slot, so a few pages
		ids := make([]RowID, n)
		for i := 0; i < n; i++ {
			id, err := f.Insert([]byte("row-" + strconv.Itoa(i)))
			require.NoError(t, err)
			ids[i] = id
		}
		require.Greater(t, ids[n-1].Page, int32(0), "the rows must span several pages")

		for i, id := range ids {
			got, err := f.Get(id)
			require.NoError(t, err)
			require.Equal(t, "row-"+strconv.Itoa(i), string(got))
		}

		require.NoError(t, f.Close())
		reopened, err := OpenFile(path)
		require.NoError(t, err)
		t.Cleanup(func() { _ = reopened.Close() })
		for i, id := range ids {
			got, err := reopened.Get(id)
			require.NoError(t, err)
			require.Equal(t, "row-"+strconv.Itoa(i), string(got))
		}
	})

	t.Run("an empty row is a live row and comes back as an empty non-nil slice", func(t *testing.T) {
		f, _ := newTestFile(t)
		id, err := f.Insert([]byte{})
		require.NoError(t, err)

		got, err := f.Get(id)

		require.NoError(t, err)
		assert.NotNil(t, got)
		assert.Empty(t, got)
	})

	t.Run("an address with no live row is ErrRowNotFound", func(t *testing.T) {
		f, _ := newTestFile(t)

		require.NoError(t, err)

		require.NoError(t, err)

				assert.Nil(t, got)
			})
		}

		f, _ := newTestFile(t)

		_, err := f.Get(RowID{Page: 0, Slot: 0})

		assert.ErrorIs(t, err, ErrRowNotFound)
	})

	t.Run("deleting a row leaves its neighbours readable", func(t *testing.T) {
		f, _ := newTestFile(t)

		require.NoError(t, err)
		b, err := f.Insert([]byte("b"))
		require.NoError(t, err)

		require.NoError(t, err)

			got, err := f.Get(id)
			require.NoError(t, err)

		// so a Get that returned a view into it would let the caller corrupt

		require.Equal(t, "abc", string(first))
		first[0] = 'X'
		second, err := f.Get(id)

		require.NoError(t, err)
		assert.Equal(t, "abc", string(second))

// Get holds only the table's read lock, like Scan, so Gets and Scans of one
// file can run at once. This is meaningful under -race.
func TestSqlFile_GetsMayRunConcurrentlyWithScans(t *testing.T) {
	f, _ := newTestFile(t)
	const n = 3000
	ids := make([]RowID, n)
	for i := 0; i < n; i++ {
		id, err := f.Insert([]byte("row-" + strconv.Itoa(i)))
		require.NoError(t, err)
		ids[i] = id
	}

	var wg sync.WaitGroup
	for g := 0; g < 8; g++ {
		wg.Add(1)
		go func(g int) {
			defer wg.Done()
			for i := g; i < n; i += 8 {
				got, err := f.Get(ids[i])
				if !assert.NoError(t, err) {
					return
				}
				assert.Equal(t, "row-"+strconv.Itoa(i), string(got))
			}
		}(g)
	}
	wg.Add(1)
	go func() {
		defer wg.Done()
		count := 0
		for _, err := range f.Scan() {
			if !assert.NoError(t, err) {
				return
			}
			count++
		}
		assert.Equal(t, n, count)
	}()
	wg.Wait()
}

```go
func (f *sqlFile) Get(id RowID) ([]byte, error) {
	numPages := f.pages.NumPages()
	if id.Page < 0 || id.Page >= numPages {
		return nil, fmt.Errorf("%w: page %d out of range [0, %d)", ErrRowNotFound, id.Page, numPages)
	}

	// Read straight from the page file, like Scan: the tail cache equals the
	// disk, so the result is the same and Get touches no mutable state.
	buf, err := f.pages.ReadPage(id.Page)
	if err != nil {
		return nil, err
	}
	if err := validateLayout(buf); err != nil {
		return nil, fmt.Errorf("page %d: %w", id.Page, err)
	}

	page := &sqlSlottedPage{buf: buf}
	if id.Slot < 0 || id.Slot >= page.SlotCount() {
		return nil, fmt.Errorf("%w: page %d slot %d out of range [0, %d)", ErrRowNotFound, id.Page, id.Slot, page.SlotCount())
	}
	row, live := page.Row(id.Slot)
	if !live {
		return nil, fmt.Errorf("%w: page %d slot %d is deleted", ErrRowNotFound, id.Page, id.Slot)
	}
	return bytes.Clone(row), nil
}
```
